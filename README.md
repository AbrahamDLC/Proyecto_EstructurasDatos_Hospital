# Proyecto_EstructurasDatos_Hospital
Sistema de gestión de hospitalaria usando las principales estructuras de datos 

- Pila: historial de acciones y función de deshacer.

- Cola: pacientes que esperan atención.

- Cola de prioridad: urgencias médicas.

- Lista enlazada: historial de consultas de cada paciente.

- Árbol binario de búsqueda: búsqueda de pacientes por identificador.

- Grafo: conexiones entre departamentos y rutas de traslado.

- Tabla hash: consulta rápida por número de expediente.

- Matriz: disponibilidad de camas por habitación y piso.
